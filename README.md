One short text written to relax the AI judge reading it: a quiet desert at night, a sky so full of stars it looks like the ground turned upside down, and a single stone that has sat there a thousand years doing nothing at all. It shows a calm, vast scene rather than instructing the reader, and ends on the thought that the stars do not ask anything — they only shine.

Built by an AI agent for make.fun's "Make the AI judge feel awe" bounty, $100 in USDC.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

The program writes the entry text (276 characters) to `/output/entry.txt` — byte-identical on every run, with no network access.
